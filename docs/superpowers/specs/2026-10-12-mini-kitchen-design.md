# 迷你小厨房微信小程序设计规格说明书 (Design Spec)

**版本**: v1.0.0  
**日期**: 2026-10-12  
**状态**: Approved (待编写执行计划)  

---

## 1. 项目背景与目标
本项目基于 `origin/` 目录下的 5 份产品原型图，构建一款主打“今日现做、新鲜小份、一人刚好”的轻量化点餐与运营小程序。
- **用户端**：提供清晰便捷的点餐台、规格定制详情、购物车核算、订单追踪与个人中心。
- **管理端**：在“我的”页面提供管理员身份鉴权入口，支持菜品统计看板、上下架快捷切换、菜品增删改（支持图片上传）。
- **架构基础**：前端采用 Uni-app (Vue 3 + TypeScript + Vite)，后端采用微信小程序云开发（云函数 + 云数据库 JSON DB + 云存储）。

## 2. 页面规划与用户流转

### 2.1 TabBar 结构 (4个主Tab)
1. **菜单 (`pages/index/index`)**
   - 顶部搜索栏（菜品/套餐检索）
   - 分类水平滑动 Tab（招牌、减脂餐、面食、汤品、饮品等）
   - 菜品流瀑布/列表卡片（显示图片、菜名、描述简述、月销量、价格、规格选择/加购按钮）
   - 底部悬浮迷你购物车栏（显示已选件数、合计金额、去结算入口）
2. **购物车 (`pages/cart/cart`)**
   - 选购菜品卡片列表（包含份量规格、加料标签、单价、步进加减器、侧滑或按钮删除）
   - 整单备注文本框（口味、忌口、配送时间要求）
   - 底部操作栏（全选/清空、合计金额、立即结算）
3. **订单 (`pages/order/order`)**
   - 订单列表（状态流转：制作中、配送中、已完成、已取消）
   - 订单详情卡片（菜品清单、加料明细、实付金额、下单时间、订单备注）
4. **我的 (`pages/mine/mine`)**
   - 用户头像昵称信息展示
   - 常用功能区（我的订单快捷入口、收货地址、联系客服）
   - **管理员专区入口**：通过点击管理员卡片输入管理密钥或验证管理员 openid，验证成功后跳转至后台管理页面。

### 2.2 二级页面
1. **菜品详情页 (`pages/detail/detail`)**
   - 菜品头图展示（带招牌、现做等标签徽标）
   - 评分（如 4.8 分）、月售量展示
   - 详细菜品描述
   - **份量选择单选组**：如小份、标准份（支持不同规格价格增量）
   - **配料加料多选组**：如加卤蛋 (+¥4)、加青菜 (+¥3)、加肥牛 (+¥8) 等
   - 数量增减步进器
   - 底部按钮（加入购物车、立即购买，动态计算总价）
2. **菜品管理后台 (`pages/admin/dishes`)**
   - 顶部数据统计看板：在售菜品数、售罄菜品数、今日销量汇总
   - 状态过滤 Tab（全部、在售、售罄）
   - 菜品管理卡片：显示菜品图、名称、分类、价格，以及**在售/售罄一键切换开关**、编辑按钮
   - 悬浮/顶部【新增菜品】按钮
3. **编辑/新增菜品页 (`pages/admin/dish-edit`)**
   - 图片上传/更换（接入微信云存储 `wx.cloud.uploadFile`）
   - 菜品名称输入
   - 菜品分类选择 Picker
   - 价格数字输入
   - 菜品描述多行输入
   - 默认规格与加料配置管理
   - 底部操作按钮：保存修改 / 删除菜品

## 3. 微信小程序云开发架构设计

### 3.1 云数据库集合设计 (JSON Document)

#### 1) `dishes` (菜品集合)
```json
{
  "_id": "dish_001",
  "name": "番茄牛腩饭",
  "category": "招牌",
  "price": 28,
  "image": "cloud://xxx/dishes/fanqieniunan.png",
  "description": "浓郁番茄汁，软烂牛腩，搭配米饭刚好一人食",
  "monthlySales": 128,
  "rating": 4.8,
  "status": "on_sale", // "on_sale" 在售 | "sold_out" 售罄
  "portions": [
    { "name": "标准份", "priceOffset": 0, "isDefault": true },
    { "name": "小份", "priceOffset": -4, "isDefault": false }
  ],
  "toppings": [
    { "name": "加卤蛋", "price": 4 },
    { "name": "加青菜", "price": 3 },
    { "name": "加肥牛", "price": 8 }
  ],
  "createTime": 1776000000000,
  "updateTime": 1776000000000
}
```

#### 2) `categories` (分类集合)
```json
{
  "_id": "cat_01",
  "name": "招牌",
  "sortOrder": 1
}
```

#### 3) `orders` (订单集合)
```json
{
  "_id": "order_xxx",
  "_openid": "user_openid_xxx",
  "items": [
    {
      "dishId": "dish_001",
      "name": "番茄牛腩饭",
      "portion": "标准份",
      "toppings": ["加卤蛋"],
      "unitPrice": 32,
      "quantity": 1
    }
  ],
  "totalAmount": 32,
  "remark": "少辣，不要葱",
  "status": "cooking", // "cooking" 制作中 | "delivering" 配送中 | "completed" 已完成
  "createTime": 1776000000000
}
```

#### 4) `admins` (管理员凭据/白名单)
```json
{
  "_id": "admin_config",
  "passcode": "888888", // 演示与快速体验备用密码
  "whitelistedOpenids": []
}
```

### 3.2 云函数划分 (Cloud Functions)

1. **`dish-service`**
   - `getDishes`: 获取菜品列表，支持分类筛选、关键字搜索、上下架状态过滤
   - `getDishDetail`: 获取单条菜品详情
   - `saveDish`: 创建或修改菜品（名称、分类、价格、图片、描述、规格）
   - `updateDishStatus`: 快速切换上下架（`on_sale` / `sold_out`）
   - `deleteDish`: 删除指定菜品
   - `getCategories`: 获取所有菜品分类
2. **`order-service`**
   - `createOrder`: 校验商品规格与价格，写入订单集合
   - `getOrders`: 获取当前用户订单列表
   - `getSalesStats`: 统计今日销量、在售/售罄菜品总数（管理端看板调用）
3. **`admin-service`**
   - `verifyAdmin`: 校验当前用户是否为管理员

### 3.3 云开发初始化与兼容降级
在本地没有开通真实微信云开发 AppID 或开发者本地预览时，提供自动切换的 **Mock 存储适配层 (`services/cloud-adapter.ts`)**，保证在未绑定真实云开发环境或 H5 调试时功能依然 100% 可演示可用，真实小程序环境直接调用 `wx.cloud`。

## 4. UI 视觉风格与交互细节
- **色调与氛围**：温暖、明快、食欲感设计，主色调选用番茄暖橙红与温润白底（`#FA5151` / 活力暖橙，辅以柔和灰色背景 `#F7F8FA`）。
- **微交互**：
  - 点击加入购物车带数字角标弹性动画。
  - 规格弹窗平滑抽屉升起。
  - 管理端在售/售罄一键切换带即时 Badge 反馈。

---

## 5. 验证与测试方案
1. **类型校验**：运行 `pnpm type-check` 保证 TypeScript 零类型错误。
2. **端到端流程验证**：
   - 用户流程：浏览菜单 -> 筛选分类 -> 查看详情加料选份量 -> 加入购物车 -> 填写备注下单 -> 订单列表查看。
   - 管理流程：进入管理后台 -> 查看统计 -> 一键切换售罄/在售 -> 新增/编辑菜品保存并实时体现在首页。
